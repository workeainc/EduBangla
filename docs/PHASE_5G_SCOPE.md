# Phase 5G Scope — Communication Notice Foundation

Phase 5G provides only tenant-safe, in-app notices. It creates draft notices,
server-resolved audiences, immutable publication deliveries and recipient read
state. It consumes existing Identity, SchoolUser, Student, Enrollment, Teacher
and Staff records without changing them.

Included: school, role and class/section audiences; school-admin draft,
publish and withdraw workflows; teacher/student/staff own inboxes; audit and
transactional lifecycle enforcement.

Excluded: parent delivery, arbitrary recipient selection, SMS/email/push,
providers, queues/retries, templates, attachments, scheduled or recurring
notices, APIs, analytics and automatic Finance/Result/Promotion notifications.
Phase 4 and Phase 5A–5F remain frozen.
