# EduBangla

## Digital Education Platform for Bangladesh

EduBangla is a Bangladesh-focused, multi-school education platform. The first release will serve one real high school while preserving secure tenant isolation, configurable academic rules, and a path to future education analytics.

The architecture is frozen for review before application implementation begins. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), [docs/DATABASE.md](docs/DATABASE.md), and [docs/ADR/0001-foundation-architecture.md](docs/ADR/0001-foundation-architecture.md).
